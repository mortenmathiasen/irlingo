# irlingo documentation

irlingo (called PIIR before version 3.0.0) sends infrared signals like a remote control does. It reads a description of a remote from a JSON file, builds the code for the buttons or settings you ask for, and transmits it: from Home Assistant through any infrared emitter, from an ESP32 running ESPHome, or with the `irlingo` command on a Raspberry Pi.

New to irlingo? Start with [Getting started](getting-started.md), which helps you choose the hardware and what controls it, and links to the guides for your choice.

## Quick start on a Raspberry Pi

For Home Assistant or an ESP32, see [Getting started](getting-started.md) instead. On a Raspberry Pi with an IR LED on GPIO 17:

```
# 1. Install the package for your Pi (see Installation for which one)
sudo apt install ./irlingo_3.5.0_aarch64.deb

# 2. Enable the kernel IR transmitter and reboot
echo 'dtoverlay=gpio-ir-tx,gpio_pin=17' | sudo tee -a /boot/firmware/config.txt
sudo reboot

# 3. Find your remote and its buttons
irlingo --list | grep -i sony
irlingo --remote sony/RM-ED011 --help

# 4. Send
sudo irlingo --remote sony/RM-ED011 --feature key=KEY_POWER
```

An air conditioner takes all its settings in one command:

```
sudo irlingo --remote hvac_panasonic --feature mode=HEAT --feature temperature=21 --feature fan=AUTO
```
